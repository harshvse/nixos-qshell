## Boot

```nix
boot.loader.systemd-boot.enable = true;
boot.loader.efi.canTouchEfiVariables = true;
```

Standard UEFI + systemd-boot. Every successful `nixos-rebuild switch` adds a
new boot entry, so rolling back a bad build is just picking an older
generation at the systemd-boot menu.

## Nix settings

```nix
nix.settings.experimental-features = [ "nix-command" "flakes" ];
nixpkgs.config.allowUnfree = true; # required for the NVIDIA driver
nix.gc = {
  automatic = true;
  dates = "weekly";
  options = "--delete-older-than 14d";
};
```

Automatic weekly garbage collection deletes generations/store paths older
than 14 days — keeps disk usage from growing unbounded across rebuilds.

## Graphics: hybrid Intel iGPU + NVIDIA (Optimus/PRIME)

```nix
hardware.graphics = { enable = true; enable32Bit = true; };
services.xserver.videoDrivers = [ "nvidia" ];

hardware.nvidia = {
  modesetting.enable = true;
  powerManagement.enable = true;
  powerManagement.finegrained = true; # lets the GPU fully power down when idle
  open = false;                       # proprietary driver (safer for Turing/1650 Ti today)
  nvidiaSettings = true;
  package = config.boot.kernelPackages.nvidiaPackages.stable;

  prime = {
    offload = {
      enable = true;
      enableOffloadCmd = true; # gives you `nvidia-offload <cmd>`
    };
    intelBusId = "PCI:0:2:0";
    nvidiaBusId = "PCI:1:0:0";
  };
};
```

- `powerManagement.finegrained` + PRIME offload (rather than sync mode) means
  the discrete GPU stays powered down until something explicitly runs on it
  via `nvidia-offload <command>` — good for laptop battery life.
- The bus IDs are hardware-specific; found via `lspci | grep -E "VGA|3D"`
  (see the top-level README's first-time-setup steps).
- `open = false` pins the proprietary NVIDIA driver rather than the
  open-source kernel module — deliberate choice for this GPU generation.

Wayland/NVIDIA-specific env vars:

```nix
environment.sessionVariables = {
  LIBVA_VDPAU_DRIVER = "nvidia";
  __GLX_VENDOR_LIBRARY_NAME = "nvidia";
  WLR_NO_HARDWARE_CURSORS = "1"; # fixes invisible/corrupt cursor on nvidia
};
```

Verifying offload is actually working (packages installed via
`home/home.nix`, see below): `nvidia-smi`, `nvtop`, `glxinfo` (mesa-demos),
`vulkaninfo`/`vkcube` (vulkan-tools), `glmark2` as a load-generating
benchmark — run any GPU tool prefixed with `nvidia-offload` and watch it
show up in `nvtop`/`nvidia-smi`.

## Hyprland (system-level enablement)

```nix
programs.hyprland = { enable = true; xwayland.enable = true; };

xdg.portal = {
  enable = true;
  extraPortals = [ pkgs.xdg-desktop-portal-hyprland ];
};
```

This just enables the compositor and its XDG desktop portal at the system
level; the actual Hyprland *config* (monitors, keybinds, theming, autostart)
lives in home-manager — see [hyprland.md](hyprland.md).

## Login: greetd + tuigreet

```nix
services.greetd = {
  enable = true;
  settings.default_session = {
    command = "${pkgs.tuigreet}/bin/tuigreet --time --cmd Hyprland";
    user = "greeter";
  };
};
```

A lightweight TUI login screen that hands off directly into Hyprland — no
display manager GUI, no session picker.

## Audio: PipeWire

```nix
security.rtkit.enable = true;
services.pipewire = {
  enable = true;
  alsa.enable = true;
  alsa.support32Bit = true;
  pulse.enable = true;
};
```

PipeWire with PulseAudio compatibility (`pulse.enable`) — this is what makes
waybar's `pulseaudio` module and `wpctl` (used in its mute-toggle click
binding) work; see [waybar.md](waybar.md).

## Fonts

```nix
fonts.packages = with pkgs; [
  nerd-fonts.jetbrains-mono
  noto-fonts
  noto-fonts-color-emoji
];
```

JetBrainsMono Nerd Font is the one font every themed app (kitty, waybar,
wofi, mako) references by name — see [theming.md](theming.md).

## User account

```nix
programs.fish.enable = true; # must be enabled at system level to be a valid login shell

users.users.harshvse = {
  isNormalUser = true;
  description = "Harsh Verma";
  extraGroups = [ "networkmanager" "wheel" "video" "input" ];
  shell = pkgs.fish;
};
```

`video`/`input` groups are needed for Hyprland to access GPU/input devices
directly as a non-root user. `wheel` grants sudo.
